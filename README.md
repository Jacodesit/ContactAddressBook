A simple contact list application built with Laravel, Inertia.js, React, and TypeScript.
It allows users to create, view, edit, and manage contacts while focusing on soft delete functionality.

Features
- Create, edit, and view contacts
- Soft delete contacts instead of permanent removal
- Restore contacts from Trash
- Permanently delete contacts from Trash
- Clean landing page with project overview
- Modal-based “Behind this” section

Tech Stack
- Laravel
- Inertia.js
- React
- TypeScript
- MySQL
- Tailwind CSS
